# Prompt: Trova cosa automatizzare

Voglio capire dove butto via tempo nella mia giornata lavorativa.
Fammi un'intervista approfondita sulla mia operatività quotidiana.
Per ogni attività chiedimi: quanto tempo ci metto, quante volte a
settimana la faccio, quanto pensiero richiede.
Alla fine crea un report con le task ordinate per (frequenza x tempo).
Sii pignolo.
