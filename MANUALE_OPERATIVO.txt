→ Cambia [ ] con [x]

→ cat ~/cervello/07-log/cron.log (vedi cosa è successo)

🔧 SE QUALCOSA SI ROMPE

Briefing non arriva:
1. cat ~/cervello/07-log/cron.log → leggi l'errore
2. bash ~/scripts/briefing.sh → test manuale
3. Se fallisce ancora: /home/genolele22/.local/bin/claude --version
   (verifica che claude sia ancora nel path)

Bot Telegram non risponde:
1. systemctl status cervello-bot
2. Se inactive: sudo systemctl start cervello-bot
3. Se fallisce: journalctl -u cervello-bot -n 30 --no-pager
